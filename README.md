# Legal Finality

**Legal Finality** is a reference definition for the point at which a decision,
order, judgment, or procedural state becomes binding and effectively irreversible.

This repository is a **public reference mirror** of the documentation site:
- Primary reference: https://legalfinality.com

## What this is
- Conceptual definitions and controlled terms
- Descriptive notes for clarity and citation
- Non-normative reference material

## What this is not
- Not legal advice
- Not a legal service offering
- Not jurisdiction-specific guidance

## Revision policy
Slow, structure-preserving updates.
